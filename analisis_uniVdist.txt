Dengan demikian, cloud dapat memilih user secara lebih selektif berdasarkan
trade-off antara revenue dan beban komputasi. Dalam formulasi knapsack,
Artinya, user yang memberikan revenue lebih besar dengan penggunaan
kapasitas yang masih feasible akan lebih mungkin dipilih. Karena itu, differ-
entiated pricing lebih fleksibel dan lebih optimal bagi edge cloud dibanding
uniform pricing, meskipun kompleksitas komputasinya lebih tinggi.
Selain itu, ketika jumlah user meningkat, kompetisi antar-user untuk
mendapatkan sumber daya komputasi cloud juga semakin kuat. Kapasitas
cloud tetap terbatas, tetapi jumlah user yang ingin melakukan offloading se-
makin banyak. Kondisi ini memungkinkan edge cloud memilih user dengan
willingness to pay yang lebih tinggi atau kontribusi revenue yang lebih besar.
Oleh karena itu, meningkatnya jumlah user dapat mendorong kenaikan harga
optimal dan revenue edge cloud. Namun, di sisi lain, semakin banyak user
juga dapat menurunkan alokasi resource per user, sehingga latency dapat
meningkat.
