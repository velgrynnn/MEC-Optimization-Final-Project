Nonconvex Pricing Problem
1. General Approach
In this paper, the authors do not handle the nonconvexity by converting the problem into
a convex problem. They also do not use local-optimization methods such as Successive
Convex Approximation (SCA), Block Coordinate Descent (BCD), or other local solvers.
Instead, the authors exploit the structure of the Stackelberg game and the closed-form
best response of the users. The solution approach is different for the uniform pricing case
and the differentiated pricing case.

7. Complexity
The dynamic programming approach has time complexity
O(K ¯F),
assuming integer weights and integer capacity.
The space complexity is
O(K ¯F)
if the full table is stored.
If only the optimal value is needed, the space complexity can be reduced to
O( ¯F)
using a one-dimensional dynamic programming array. However, if the selected users
must be recovered, then either the full table or an additional decision table is needed.
The dynamic programming method gives the global optimum for the reformulated
differentiated-pricing problem. It is not a local solver like SCA or BCD. However, its
complexity is pseudo-polynomial, because it depends on the numerical value of the ca-
pacity ¯F, not only on the number of users K.
